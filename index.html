⚙️ Grid Parameter Setup

Players may establish the grid parameters themselves or allow the system to randomly generate them.

Capacity Added After Each Brownout

Set the number of additional electrons added after each brownout. Each value must be between 5 and 15.

🎲 Randomized Grid Parameters

The system will randomly determine:
  • Initial capacity: 30–50 electrons
  • Number of brownouts before blackout: 1–6
  • Capacity added after each brownout: 5–15 electrons
Note: Grid capacity and the brownout limit will remain hidden from players during gameplay.
