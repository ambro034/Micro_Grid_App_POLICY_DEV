Neighborhood Initialization Portal

Register the neighbors currently sitting at your table. Then choose whether to establish the grid parameters manually or randomize them.

⚙️ Grid Parameter Setup

Players may establish the grid parameters themselves or allow the system to randomly generate them.

Capacity Added After Each Brownout

Set the number of additional electrons added after each brownout. Each value must be between 5 and 15.

🎲 Randomized Grid Parameters

The system will randomly determine:
  • Initial capacity: 30–50 electrons
  • Number of brownouts before blackout: 1–6
  • Capacity added after each brownout: 5–15 electrons
Note: Grid capacity and the brownout limit will remain hidden from players during gameplay.

📜 Game Policies

Select the policies that will govern neighborhood electricity use during gameplay. Multiple policies may be active at the same time.

No Policies is the default.

Policies may be selected individually or in any combination.
🛠️ Policy Design Options
Select at least one Game Policy above to refine its design.
⚠️ System Fines for Exceeding Capacity
Choose the fine charged for each electron by which a purchase exceeds the grid's available capacity.

Default: $50 per excess electron.
💡 Flexible Billing Rates
The normal electricity rate is fixed at $20 per electron.

When neighborhood demand comes within 10e of grid capacity, the selected high-demand rate will apply.

Default high-demand rate: $30 per electron.
📢 System Updates for Customers
Choose which pre-purchase system warnings customers receive.

If more than one enabled warning applies to a purchase, only the most severe applicable warning will be shown.
